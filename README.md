# 白色失明文字麻将 V7

多人联机文字麻将。Node.js + Socket.IO。

## 本地启动

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

## V7 核心规则

- 2–8 人。
- 开局每人 13 张牌。
- 轮到自己时先摸 1 张，然后可以按点击顺序选择至少 2 个字提交出牌，或选择“跳过不出”。
- 允许使用谐音字，只要多数玩家认可即可。
- 出牌后由其他玩家投票；认可票超过其他玩家人数的一半才成立。
- 出牌不通过：整组牌退回，仍由该玩家重新操作。
- 出牌通过：这些牌永久离开手牌，不再自动补回 13 张。
- 每成功打出 1 个字，本局 +1 分。
- 最先打光全部手牌的玩家立即获胜，并额外 +10 分。
- 房主可以随时重开本局；重开只清本局分，房间累计积分继续保留。
- 只要房间仍存在，累计积分会保留；所有玩家都离开、房间销毁后才清空。
- 同一浏览器重新加入同一房间时，会按本地玩家标识恢复该玩家在房间内的累计积分。
- 左侧显示房间累计积分榜；离线过但仍在房间记录中的玩家也会保留在榜单里。
- 牌河区域固定高度，可上下滚动。
- 桌边消息区分系统消息和玩家聊天。

## V7 词库新增

新增并强化：

`前、现、任、偷、背、绿、醋、亲、爱、舔、追、甩、分、婚、约、睡、抱、哄、骗、查、删、拉、黑、菜、坑、躺、带、飞、送、连、跪、炸、竟、敢、又、还、真、都、只、才、居、然、因、为、但、是、报、警、给、小、大`

其中高频梗字会有重复牌，以提高成句率。

## 部署

可直接部署到支持 WebSocket 的 Node.js 托管平台，例如 Railway。

Build Command:

```text
npm install
```

Start Command:

```text
npm start
```


## V8 更新

- 牌库新增 `骚 ×2`。
- 手牌达到 15 张时自动缩小并允许多排展示；达到 21 张时进一步缩小，避免横向无限延伸。
- 房主右上角新增两个管理按钮：
  - `重开本局`：重新洗牌、重新抓牌，清空本局积分，但保留房间累计积分。
  - `结束对局`：按房间累计积分结算排名，并立即关闭房间；原房间码失效，所有玩家返回大厅。


## V10 界面修复

- 自己的玩家名牌改为手牌区上方独立占位，不再作为牌桌绝对定位浮层，因此不会遮住手牌。

## V11 手机端适配

- 手机竖屏改为独立响应式布局。
- 手牌在手机上始终自动多排，禁止横向溢出屏幕。
- 房间信息与房主操作按钮自动压缩换行。
- 牌河、投票框、聊天区针对窄屏缩放并支持纵向滚动。
- 兼容窄屏与较矮的手机浏览器视口，并考虑底部安全区。

## V12 更新
- 对局中断线/切出后，可用原昵称 + 房间号重新加入，恢复原手牌、座位与累计积分。
- 同一页面发生短暂网络断开时会自动尝试回到原房间。
- 每回合 30 秒倒计时；到时未完成操作自动“跳过不出”。
- 房主结束对局后，全员看到最终累计积分榜，5 秒后统一返回大厅；房间同时关闭、房间码失效。


## V13 更新

- 回合倒计时改为：摸牌前不计时，摸牌后45秒。超时自动跳过不出。
- 房间累计积分达到30分判定获胜。
- 新增四个任意局内阶段可用的快捷语音/提示：我等的花儿都谢了、请喝卡布奇诺、牛逼、垃圾。
- 大厅和等待区域增加简要玩法说明。

- 快捷互动支持连击显示：同一句在 3 秒内连续触发，会显示 +1、+2、+3……。
