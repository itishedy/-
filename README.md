# 陪玩梗文字麻将

一个可多人联机的文字麻将 MVP。房主创建房间，朋友输入房间码加入；每人13张，轮到自己先摸到14张，然后一次提交至少3个字。其他玩家投票认可，**认可票超过其他玩家人数的一半**后才算出牌成功。

## 本地启动

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

## 公网部署

这是普通 Node.js + Socket.IO 项目，可直接部署到支持 WebSocket 的 Node 托管平台（如 Render、Railway、Fly.io、VPS 等）。部署后把网址发给朋友即可。

## 当前规则
- 2–8人
- 每人常态保持13张手牌
- 轮到自己时先摸1张，变成14张
- 每次提交出牌必须一次选择 **至少3个字**
- 出牌后进入“全桌认可”阶段，出牌者本人不能投票
- 认可票必须 **超过其余玩家人数的一半**：例如3名其他玩家需要2票，4名其他玩家需要3票
- 一旦认可票达到过半，出牌立即成立：进入弃牌区，系统自动补牌到13张，然后轮到下一位
- 如果剩余票数已经不可能达到过半，立即判定失败：整组牌退回原玩家手里，仍由该玩家重新组织并出牌
- 同一玩家对同一组出牌只能投一次票
- 摸到14张后，可以不出牌而直接尝试胡牌
- 胡牌句子必须恰好使用手牌所有14个汉字；标点和空格忽略
- 当前胡牌不做自动语义判断

## 下一步建议
