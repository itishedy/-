# 白色失明文字麻将

一个可多人实时联机的文字麻将网页游戏。

## 当前规则

- 2–8 人开房联机。
- 每人常态保持 13 张手牌。
- 轮到自己时先摸 1 张，变成 14 张。
- 每次出牌必须一次选择至少 3 个字。
- 出牌后由除出牌者之外的玩家投票；认可票必须超过其他玩家人数的一半。
- 投票通过：该组牌进入牌河，系统自动补牌到 13 张，然后轮到下一位。
- 投票失败：整组牌退回出牌者手里，仍由该玩家重新组织出牌。
- 摸牌后的 14 张可以尝试胡牌；胡牌句子必须正好使用全部 14 张牌，标点和空格不计。

## 本地启动

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

## Railway 部署

连接 GitHub 仓库后直接部署即可。项目会读取 Railway 提供的 `PORT` 环境变量。
